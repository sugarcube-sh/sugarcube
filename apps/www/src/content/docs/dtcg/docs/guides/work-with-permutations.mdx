If your resolver has modifiers (e.g. light and dark modes) a token can have a different value in each permutation. `color.text` might be dark gray in `mode: light` and white in `mode: dark`. That means you'll likely need to work with permutations.

## Get one permutation

To get one permutation, pass an input to [`getPermutation`](/dtcg/docs/reference/design-tokens/#getpermutation):

```ts
import { read } from "@sugarcube-sh/dtcg/node";

const tokens = await read("tokens.resolver.json");
const dark = tokens.getPermutation({ mode: "dark" });

dark.getToken("color.text")?.resolvedValue;
// { colorSpace: "srgb", components: [1, 1, 1], alpha: 1 }
dark.label;
// "mode: dark"
dark.input;
// { mode: "dark" }
```

## Show a token's value in every permutation

To list every token's value in light and dark, use [`groupPermutationsBy`](/dtcg/docs/reference/design-tokens/#grouppermutationsby). Note that a token that's the same in both is listed once.

```ts
import { toCSSValue } from "@sugarcube-sh/dtcg/css";

for (const path of tokens.tokenPaths) {
  const groups = tokens.groupPermutationsBy((permutation) =>
    toCSSValue(permutation.getToken(path)),
  );
  for (const { result, permutations } of groups) {
    console.log(path.padEnd(18), permutations.label.padEnd(18), result ?? "no value");
  }
}
// color.white        every permutation  rgb(255 255 255)
// color.gray.800     every permutation  rgb(51 51 51)
// color.blue.300     every permutation  rgb(153 204 255)
// color.blue.500     every permutation  rgb(51 102 204)
// color.text         mode: light        rgb(51 51 51)
// color.text         mode: dark         rgb(255 255 255)
// color.background   mode: light        rgb(255 255 255)
// color.background   mode: dark         rgb(51 51 51)
// color.accent       mode: light        rgb(51 102 204)
// color.accent       mode: dark         rgb(153 204 255)
// color.link         mode: light        rgb(51 102 204)
// color.link         mode: dark         rgb(153 204 255)
// color.focus        every permutation  no value
```

## Show what one permutation changes

To see which tokens dark mode changes, compare it with light using [`getTokensDifferentFrom`](/dtcg/docs/reference/permutation/#gettokensdifferentfrom):

```ts
const light = tokens.getPermutation({ mode: "light" });

dark.getTokensDifferentFrom(light).map((token) => token.path);
// ["color.text", "color.background", "color.accent", "color.link"]
```
