## Import paths

dtcg is split into a few import paths.

<Table>
| Import | What it's for |
| --- | --- |
| [`@sugarcube-sh/dtcg`](/dtcg/docs/reference/dtcg/) | Reading tokens anywhere |
| [`@sugarcube-sh/dtcg/node`](/dtcg/docs/reference/node/) | Working with token files on disk |
| [`@sugarcube-sh/dtcg/css`](/dtcg/docs/reference/css/) | Writing CSS |
| [`@sugarcube-sh/dtcg/editor`](/dtcg/docs/reference/editor/) | Pointing at places in a file |
| [`@sugarcube-sh/dtcg/values`](/dtcg/docs/reference/values/) | Working with single values |
</Table>
