Sugarcube supports modern color spaces like OKLCH and Display P3, and writes them as CSS as they are.

## Supported color spaces

sugarcube writes every DTCG color space: sRGB, sRGB Linear, HSL, HWB, CIELAB, LCH, OKLAB, OKLCH, Display P3, A98 RGB, ProPhoto RGB, Rec 2020, XYZ-D65 and XYZ-D50, plus hex. A color in `srgb`, `hsl`, `hwb`, `lab`, `lch`, `oklab` or `oklch` is written as that CSS function, such as `oklch(0.7 0.3 328)`, and the rest as `color()`, such as `color(display-p3 1 0 0)`.

## Color fallbacks

sugarcube writes modern color spaces as they are, without fallbacks:

```css
:root {
  --color-primary: oklch(0.7 0.3 328);
}
```

<SiteAside type="caution">
    `colorFallbackStrategy: "polyfill"` is deprecated. It still works, with a warning, and will be removed in a later release. It writes each color's `hex` first, then the color itself inside an `@supports` check for its color space. A color outside sRGB and HSL with no `hex` warns, and is written as it is.
</SiteAside>
