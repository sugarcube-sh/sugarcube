The internals of [sugarcube](https://sugarcube.sh)'s build tool: reading your config and tokens, and writing CSS.

You don't need to install it. [`@sugarcube-sh/cli`](https://www.npmjs.com/package/@sugarcube-sh/cli) and [`@sugarcube-sh/vite`](https://www.npmjs.com/package/@sugarcube-sh/vite) bring it with them, and its API is for them alone, so it can change in any release. To use sugarcube, start with the [docs](https://sugarcube.sh/docs/introduction/).
